# Hemu Diorama · Polyfork Alpine Kit (lab)

The Hemu (Jikepulin) tabletop diorama from eric1hua/hemu-ski, re-dressed with
the free low-poly kit "Alpine and Snow" from Polyfork
(https://polyfork.dev/kit/alpine-and-snow-092f66) — an asset-swap experiment.

- The game's forest is replaced by the kit's snow-laden spruces, windblown
  larches and bare rowans on the game's own toy-forest spots (2,287 trees).
- Alpine chalets, hay barns and village props form villages around the East
  and West service centres; the summit gets the kit's cross, weather mast,
  top station and refuge hut; named runs get marker poles, and the main run
  gets slalom gates, a race-start hut, a patrol hut, fences and nets.
- 46 of the kit's 59 parts are used (2,933 placements). The animated lifts,
  riders, terrain and run map are the game's own, unchanged.
